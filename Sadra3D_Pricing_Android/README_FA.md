# تعیین قیمت صدرا 3D — نسخه اندروید بومی (Java)

این پروژه **اپلیکیشن واقعی اندرویدی** است؛ نه وب‌اپ یا WebView. تمام محاسبات روی گوشی و بدون اینترنت انجام می‌شوند.

## امکانات
- محاسبه خودکار هزینه مواد، دستگاه، نیروی کار، سود و قیمت نهایی
- نرخ‌های قابل ویرایش با مقادیر پیش‌فرض فایل اکسل
- لوگوی صدرا 3D و فونت Yekan Bakh ExtraBold ارسالی
- طراحی فارسی و راست‌چین با تم قرمز
- نگهداری تنظیمات و تاریخچه محاسبات روی گوشی
- بازیابی و حذف موارد تاریخچه
- خروجی PDF از طریق انتخاب محل ذخیره توسط کاربر (بدون نیاز به دسترسی حافظه)
- اشتراک‌گذاری خلاصه محاسبه
- بدون نیاز به سرور، اینترنت، حساب کاربری یا مجوزهای حساس

## منطق کاملاً مطابق فایل price 3d.xlsx
- `C3 = (A3*(B9/1000))+(B3*B10)+((B3*0.05)*B11)`
- `E3 = C3+D3*C3/100`

در این برنامه:
- وزن بر حسب **گرم**؛ B9 قیمت هر **کیلوگرم**
- B3 زمان چاپ بر حسب ساعت
- B10 هزینه هر ساعت دستگاه
- B11 هزینه هر ساعت نیروی کار (ضریب مصرف نیروی کار برابر با ۰٫۰۵ ساعت به ازای هر ساعت کار دستگاه)
- D3 درصد سود
- فرمول‌ها از فایل اکسل تغییر نکرده‌اند.

نمونه رسمی اکسل: وزن ۷۵ گرم، زمان ۳ ساعت، سود ۱۰۰٪، نرخ مواد ۶٬۰۰۰٬۰۰۰، دستگاه ۳۰٬۰۰۰ و نیروی کار ۳۰۰٬۰۰۰ → هزینه خالص ۵۸۵٬۰۰۰ و قیمت نهایی ۱٬۱۷۰٬۰۰۰.

**توجه:** خود فایل اکسل واحد پولی را مشخص نکرده است. مبالغ در برنامه با همان واحد عددی ورودی نمایش داده می‌شوند.

## ساخت APK با Android Studio
1. پوشه پروژه را از ZIP استخراج کنید.
2. در Android Studio گزینه **Open** را انتخاب کرده و پوشه `Sadra3D_Pricing_Android` را باز کنید.
3. اجازه دهید Gradle و Android SDK نصب شوند. پروژه از Android Gradle Plugin `8.7.3`، Gradle `8.9` و SDK `35` استفاده می‌کند؛ JDK 17 نیاز است.
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی نصب‌شدنی را بسازید.
5. APK در `app/build/outputs/apk/debug/app-debug.apk` تولید خواهد شد.

این بسته حاوی سورس و تنظیمات پروژه است؛ Gradle Wrapper JAR و Android SDK داخل بسته قرار نگرفته‌اند. برای ساخت بدون نصب Android Studio نیز می‌توانید پروژه را در یک مخزن GitHub قرار دهید و Workflow آماده `.github/workflows/build-apk.yml` را اجرا کنید؛ فایل APK از بخش Artifacts قابل دریافت خواهد بود.

## نکات امنیتی و انتشار
- فایل Debug APK برای تست قابل نصب است اما برای انتشار گسترده، نسخه Release با کلید امضای اختصاصی بسازید.
- داده‌های تاریخچه در SharedPreferences محلی ذخیره می‌شوند و برای استفاده شخصی مناسب‌اند.
- اگر نسخه چندکاربره یا هماهنگی ابری لازم باشد، به دیتابیس و احراز هویت نیاز خواهد بود.
